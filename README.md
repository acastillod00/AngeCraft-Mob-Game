# AngeCraft: Mob Hunt

**Author:** Angelica
**Playable Link:** https://acastillod00.github.io/AngeCraft-Mob-Game/

## Goal
Survive until the 2:30 sunset timer ends by hunting down hostile mobs (Zombies, Creepers, Skeleton Archers, and the Dread Brute Boss) in the voxel village arena.

## Controls
* **Click Screen:** Lock mouse to look around
* **W / A / S / D:** Move
* **Shift:** Sprint
* **Spacebar:** Jump (hit mid-air with the sword for a 1.5x Critical Hit)
* **Left-Click:** Attack / Shoot Crossbow / Place Blocks / Eat Golden Apple / Use Shockwave Totem
* **Right-Click:** Raise Shield (blocks 80% damage)
* **1 – 5 Keys:** Switch weapons/items
* **Tab:** Unlock mouse cursor to click hotbar items directly
* **ESC:** Pause

## How to Run
Open the playable link above in Chrome, Edge, Firefox, or Safari—no downloads or setup needed.
